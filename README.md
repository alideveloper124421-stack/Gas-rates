# LPG Gas Cylinder Rate & Bill Calculator (ایل پی جی حساب کتاب)

Android APK اور آف لائن بلنگ سسٹم - ایل پی جی گیس سلنڈر ریٹ، کمرشل اضافی چارجز، اور رومن اردو الفاظ میں کاؤنٹنگ کے ساتھ۔

---

## 📱 Android APK ڈاؤن لوڈ اور موبائل میں انسٹال کرنے کا طریقہ

### 1. گٹ ہب سے ڈائریکٹ APK ڈاؤن لوڈ کریں:
1. کوڈ پش کرنے کے بعد GitHub پر اپنی ریپو کے **Actions** ٹیب پر جائیں۔
2. **Build Android APK** والے ورک فلو پر کلک کریں۔
3. پیج کے آخر میں **Artifacts** کے نیچے **`LPG-Hisab-Kitab-Android-APK`** نظر آئے گا۔
4. اس پر کلک کریں، آپ کے موبائل میں اصلی انسٹال ایبل **`LPG-Hisab-Kitab-v1.0.apk`** ڈاؤن لوڈ ہو جائے گا!
5. اس APK پر ٹیپ کر کے اپنے موبائل میں انسٹال کر لیں اور آف لائن استعمال کریں۔

---

## 🛠️ GitHub پر پش کرنے کا طریقہ (Push to Build APK)

اپنے ٹرمینل میں یہ کمانڈز چلائیں:

```bash
git add .
git commit -m "feat: add android capacitor project and apk build workflow"
git push
```

جیسے ہی آپ پش کریں گے، GitHub Actions خود بخود:
1. ویب کوڈ اور ٹیسٹس بلڈ کرے گا۔
2. اینڈرائیڈ گریڈل کے ذریعے **`LPG-Hisab-Kitab-v1.0.apk`** جنریٹ کرے گا۔
3. آپ کو تیار شدہ APK فائل فراہم کر دے گا!
